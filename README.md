# AI Customer Support Automation System

This project demonstrates an AI-powered enterprise customer support workflow using n8n, OpenAI, Pinecone, and Gmail API.

The workflow automatically:
- monitors incoming customer emails
- retrieves contextual answers from enterprise knowledge bases
- generates AI-powered support responses
- sends professional threaded email replies

---

- AI-powered customer support automation

- AI agents using n8n
- Contextual enterprise knowledge retrieval
